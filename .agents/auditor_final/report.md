    $$\text{Saldo Neto} = (\text{Total Flota} + \text{Total Guía} + \text{Total Farmacia}) - \text{Total Anticipos}$$
  * `CompanionShift.ts`, `DriverTransfer.ts`, `ReceiptExpense.ts`, `PatientBooking.ts`: Fully realized domain entities with pure TypeScript methods.
- **Application Layer (`src/application/`)**:
  * CQRS Use Cases (`CreateEventUseCase`, `RescheduleEventUseCase`, `SettleExpenseUseCase`, `ReconcileSettlementUseCase`, `SignOffItineraryUseCase`, `ExportSettlementPDFUseCase`, `LoadArchetypeUseCase`, `PersistStorageUseCase`) interact exclusively via abstract ports (`IStoragePort`, `IBlobStoragePort`, `IOCRPort`, `IExportPort`).
- **Infrastructure Layer (`src/infrastructure/`)**:
  * `DexieStorageAdapter.ts`: Genuine IndexedDB implementation using Dexie v4 managing 8 tables (`bookings`, `events`, `shifts`, `transfers`, `expenses`, `settlements`, `blobs`, `event_stream`).

  * `SimulatedReceiptOCRAdapter.ts`: Optical text parsing with NIT extraction, vendor matching, line-item classification, and total amounts in integer cents.
